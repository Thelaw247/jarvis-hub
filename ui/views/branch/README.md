# Branch page (V03d)

`<jv-branch-page branch-id>`: header, at most six panels (Status, Due, Next, Open loops, Key facts, Recent), the rest under More (People, Files, Decisions, Not known yet, Summary), a children strip and branch settings. Beside the Life Map (`beside-map`) the children strip is left out, because the map already shows them. Private branches stay locked on a shared screen. Branch settings answer honestly in demo mode (nothing is changed).

Scenes: `branch-course`, `branch-parent`, `branch-empty`, `branch-proposed`, `branch-private-shared`. Add `&theme=evening` or `&size=laptop|phone|ambient`. Details are in the comments at the top of each file.
