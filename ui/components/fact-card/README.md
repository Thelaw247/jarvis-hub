# jv-fact-card (C08)

One fact: statement, source chip, confidence in words, history and conflict (shown resolved his way with one toggle). Confirm stays visible on anything Jarvis isn't sure of; Edit · Pin as rule · Move · Forget sit behind one "…" button (Esc closes it). The card is named by its statement and every button says which fact it acts on ("Edit: …"). Guesses get the dotted underline and say what they were guessed from. Forget previews what else goes. `.fact`, `.branches`, `compact`.

Scene: `?scene=component:fact-card` (add `&state=<name>` for one state, `&theme=evening` for Evening). Details are in the comment at the top of `fact-card.js`.

On the Stage's glass board (HUD v3, `jv-window[opens]`) the statement is dense (14/20).
