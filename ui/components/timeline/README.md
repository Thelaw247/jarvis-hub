# jv-timeline (C18)

The day as a calm list: classes, Jarvis's blocks and his own events, each with time, kind (icon + word), source chip and "Why this time?". Done items are ticked; a dashed line marks now. `.items`, `.now`, `compact`.

Scene: `?scene=component:timeline` (add `&state=<name>` for one state, `&theme=evening` for Evening). Details are in the comment at the top of `timeline.js`.
