# jv-working-on (C20, Night pass N5a)

Mono chips for what Jarvis is doing in the background, with real progress only: a segmented scan bar (2
elements) lit up to the reported share while a cyan chunk sweeps across; plain words ("· working") when the job
can't report a number. Finished jobs show the done glance; failed ones the "needs you" glance with what to do in
the title and for screen readers. Reduced motion and the strip: no sweep, words and numbers only. `.jobs`.

Scene: `?scene=component:working-on` (add `&state=<name>` for one state, `&theme=day` for Daylight).
