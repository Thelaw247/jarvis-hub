# jv-plant (C17)

Pen Reader's leaf family, drawn in the browser (a port of `tools/make_plants.py`). `kind="day"` grows a leaf for each thing done today (`.done`, `.total`) and blooms when all are done; also `potted`, `sprig`, `leaf`. Exports the leaf and pot geometry for the Life Map (the focus is a pot, branches are leaves).

Scene: `?scene=component:plant` (add `&state=<name>` for one state, `&theme=evening` for Evening). Details are in the comment at the top of `plant.js`.
