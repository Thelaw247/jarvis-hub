# jv-branch-card (C14, Night pass N5a)

The briefing for one branch, sized for a glance: its picture (`branch.thumb`) or monogram and its name in the
condensed face, the nearest Due with its glance code (soon within 72 h, critical when past, otherwise its real
progress) and a big countdown (or a parent's roll-up when nothing is due), the Next event, one key fact with its
source, and Open. Open loops, people, files and the summary live on the branch page. Tier-2 branches don't
render on the ambient screen. `.card`, `.branch`, `.facts`, `.now`.

Scene: `?scene=component:branch-card` (add `&state=<name>` for one state, `&theme=day` for Daylight).
